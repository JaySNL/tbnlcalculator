# TBNL Battery Calculator

A modern, SEO-optimized battery capacity calculator for [ThuisbatterijNederland.nl](https://thuisbatterijnederland.nl/).

## 🎯 Project Overview

An intuitive battery storage calculator that helps Dutch homeowners determine optimal battery capacity and inverter size. Designed to balance simplicity with power - not too basic, not too complex.

## 🏗️ Architecture

- **Frontend**: Vite + Vanilla JS + HeroUI
- **Integration**: WordPress embed via `<script>` tag (hybrid approach)
- **Hosting**: Vercel (CDN-backed)
- **Analytics**: Plausible
- **SEO**: Progressive enhancement with static HTML fallback
